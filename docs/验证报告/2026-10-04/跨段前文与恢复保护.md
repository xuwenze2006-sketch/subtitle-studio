# 跨段前文与恢复保护

日期：2026-10-04

新建 DeepSeek 任务支持跨音频切段的前文：取紧邻上一段已验证原文中的最多两句，时间必须在本段第一句之前、不重叠、相隔不超过 15 秒。参考内容总长度最多 1,200 字符，超长时整句省略；原字幕与时间轴不变。只等紧邻前段的识别结束，不等后段，也不等待前段翻译，保留 ASR 并发与识别、翻译重叠执行。

调度器在首次提交前将实际前文、原索引和绝对时码、两段源文哈希及快照摘要写入 state.json。恢复时严格复用按当前源文哈希保存的快照，空上下文同样保存。邻段后来恢复或修改不改变已提交请求；当前原文改后又还原可复用原快照。源缓存丢失后重建时保留上下文历史，防止同一文本形成不同的付费请求。

旧任务没有新版本标记时保持旧请求格式，既有完成字幕不自动重译。新任务的策略标记缺失、快照缺失或损坏、状态写入失败时阻断新翻译。worker 读取同一份原文字节并计算哈希，在输出前复查；运行中原文变化不会将旧译文绑定到新源文。

适配器将跨段前文表示为负数只读 ID，不加入实际翻译项；内部前文逐步替换外部前文，前译查找不使用 Python 负下标。实际发送的前文计入缓存身份、输入长度及费用预留；没有新增润色调用。

## 验证

- 本轮新增 22 项用例，覆盖跨段请求、混合邻居、语言与 ID 保持、取消恢复、预留费用、时间筛选、快照历史、乱序 ASR、首段及时翻译、邻段失败、丢失快照、保存失败、策略丢失、源缓存重建、翻译中原文修改和旧任务兼容。
- 集成阶段全量离线测试 591 项：590 通过，1 项既有跳过。日志：`output/cross-chunk-context-fix/offline-all.log`。
- 最后两处恢复保护修复后，相关适配器、快照、runner 与千问流程共 114 项回归再次通过。命令：`python -X utf8 -m unittest tests.test_runner_context tests.test_translation_context tests.test_deepseek_translate tests.test_runner tests.test_qwen_pipeline`。
- 独立只读审查发现并复现源缓存重建丢失快照的问题，新增失败回归后修复；最终审查无剩余阻断项。
- 真实项目 2602 个受保护文件的内容、大小及文件标识未变；未产生新人工检查记录或云端调用。

本次验证的是程序行为、缓存与费用保护，不是实际模型翻译质量。跨段只读取紧邻前段的原文，不提供全片剧情记忆；旧的两部字幕没有被重新润色。完整任务状态应与字幕、缓存一起保留。
