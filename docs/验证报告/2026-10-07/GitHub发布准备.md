## 结果与范围

本机候选已通过源码完整性、独立目录安装构建、默认前端测试和虚拟环境后端回归。当前没有配置 Git 远端；没有上传 GitHub、发布版本或调用真实识别/翻译接口。

本次提交整理同时纳入此前未提交的人工校对、多语言、断点与导出恢复功能，以及维护和安全修复。修改前的完整候选快照保存在忽略目录 `output/验证记录/2026-10-07/github-ready/before-source.zip`，不会用 Git 重置覆盖已有工作。

## 本轮新增修复

- 正式导出视频现在核对来源绑定和实际 SHA-256。被覆盖、替换或与来源不符的文件不再作为已验收成片开放。复用已有最多 8 项文件身份缓存，未变化文件的状态、预览和下载不重复扫描整部视频；首次读取仍需要计算摘要。
- Windows 进程回收现在保留自有 Job 成员的原生句柄，确认所属关系后终止 Job，等待成员归零和已保留句柄的退出信号。成员等待共用 4 秒截止，错误不覆盖原取消原因，随后继续执行原父进程退出确认。
- 崩溃恢复测试绕过 Windows venv 外层启动器，同时保留虚拟环境导入路径。继续严格校验实际工作进程 PID 与自有句柄，不通过放宽断言掩盖问题。
- 增加 `tests/__init__.py`，避免安装环境中的同名 `tests` 包抢占仓库测试辅助模块。
- 声明 Node 24.15–24.x；说明 Python 3.14 / Tcl/Tk、FFmpeg / libass、本地 Whisper 和 Intel QSV 要求。README 改为可在新机器使用的安装入口，详细操作另放使用指南。
- 增加 Windows GitHub Actions、固定 Action 提交 SHA、只读权限、依赖更新配置和源码/构建一致性检查。CI 检查已提交的差异，而不是对干净 HEAD 作无效工作区比较。工作流尚未在远端运行。
- 补充环境配置和密钥文件忽略规则、统一文本行尾。个人操作记录和一次性处理脚本保留在本机，从发布候选排除。

## 使用及发布边界

现有 Git 历史仍保留原作者身份和早期个人操作记录，没有重写历史。另提供的源码 ZIP 只包含清理后的当前文件；如要首次公开建仓，可使用该源码包建立新历史。保留原本地仓库用于追溯。

Windows 保护仍从 Job 绑定成功后开始；进程成员快照与终止之间也有极窄的创建窗口。本轮修复不声称彻底消除所有进程创建竞态。实现依据为 [Microsoft Job Objects](https://learn.microsoft.com/en-us/windows/win32/procthread/job-objects) 与原生进程等待语义。

本轮没有重新压制真实整片、调用云端服务或进行人工字幕验收。已有前端的浏览器验证见同目录维护加固报告；本轮前端产物未改变。成片首次摘要读取仍受磁盘速度影响，文件缓存不抵御刻意伪造全部元数据的修改。

当前运行的旧服务未重启。完成或停止任务后重新启动后端，才会加载新修复；只刷新页面不够。
