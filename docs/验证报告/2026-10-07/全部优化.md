范围是未保存校对输入恢复、长字幕响应、环境兼容、真实媒体检查和导出模块维护。变更在独立工作区实施，个人素材、任务、账本与原始 Git 历史没有作为公开提交内容，也没有调用识别或翻译服务。

## 行为与维护

- 校对草稿在当前浏览器保留 7 天 / 30 个项目片段 / 1 MiB。白名单字段不包含凭据；正式版本冲突不自动合并，多窗口新稿不能被旧稿保存回执清除。存储不可用仍保留当前输入和正式保存入口。默认启动复用上次浏览器端口，Windows 使用独占监听；端口被占用时提示地址变化。
- 校对写入保持项目锁与严格修订校验，返回单句小回执，避免提交后重复构建整份预览。播放时间索引保持重叠条目第一匹配及无 ID 旧结果的行为。任务运行时读取内存进度，定期或在完成/项目/操作变化时更新完整状态。
- 启动后检查 Python、Tk/Tcl、FFmpeg/ffprobe、字幕滤镜、本地模型文件和编码器实际运行能力。自动模式在新编码前探测 QSV，失败则用 CPU；显式选择严格执行。已证明完成的结果恢复继续复核内容，不要求当前机器还能运行原编码器。
- `media_export.py` 承担压制、音轨校验、编码身份与发布恢复；`environment.py` 承担有时限探测。工作流通过明确依赖接口调用，旧 QSV 证据仅在其他身份完全一致时兼容。
- 独立真实媒体验收工具覆盖 H.264 / HEVC / 多音轨、字幕画面、完成后取消恢复和真实编码中停止。详细证据见 [真实媒体验收](真实媒体验收.md)。

## 保存响应测量

运行 `python tests/studio_review_benchmark.py`，每种模式预热一次后记录三次提交，包含严格磁盘校验、写入、视图构建和 JSON 编码；每次对照重新读取的完整预览，最终视图均等价。

| 合成字幕数 | 全量回执中位耗时 | 单句回执中位耗时 | 全量响应 | 单句响应 |
| --- | --- | --- | --- | --- |
| 5,000 | 280.331 ms | 112.890 ms | 1,254,218 字节 | 749 字节 |
| 20,000 | 617.135 ms | 516.868 ms | 5,114,220 字节 | 750 字节 |

耗时会随磁盘和并行负载变化；此前同机另一轮 20,000 句为 1064.171 / 454.607 ms。响应体减少是稳定结果，这些数字不证明浏览器所有操作的延迟，也不改变云端识别速度。
