# 第37轮：成片检查期间保持字幕可用

基线 `080ca375a9b315d07a0c913718ea4dee75d9b7c8`。用户要求优先解决最值得改进的问题，浏览器验收后上传 GitHub。本轮聚焦已有 MP4 的冷校验阻塞工作台；上次五轮反思35，下次40。

## 问题依据

原先状态读取会为了显示文件位置验证整个审核版 MP4，字幕预览也会在返回字幕前验证已有成片。第一次完整摘要既消耗文件读取时间，又持有共享校验缓存锁，因此多个页面读取可能一起等待。前端普通读取15秒超时后，连工作台连接和字幕编辑也不可用。

实现前，用自建18.2秒双音轨 MP4、明确标注的合成发布回执和真实生产页面复现：仅在实际输出摘要内部延迟17秒，浏览器 `/api/state` 在15007毫秒中止，显示“本地服务未连接”和“读取本地服务数据超时”。独立后端屏障持续15.203秒时，state与preview仍未完成，progress正常返回；释放后两者成功，只摘要一次。这证明依赖关系，不是物理磁盘吞吐或真实长片性能测量。

## 实现范围

工作台和字幕页面使用轻读取。字幕先显示，成片在独立区域检查；超过15秒继续说明大文件可能需要更久，实际失败提供局部重试。普通连接期限不变，不增加自动重试、后台任务系统或整视频前端缓存。

轻读取只复用已经完成、与摘要和当前文件代际一致的校验缓存。缓存锁忙时立即跳过文件位置，不能重新排队等待正在进行的摘要。载入项目的状态回执和任务启动前的资格检查也避开无关成片正文读取。

独立成片结果受当前项目、片段和校对修订约束。字幕保存、刷新、切换与卸载撤销旧请求所有权；迟到的结果不能覆盖字幕编辑或恢复旧下载入口。媒体播放和实际下载继续使用原有完整文件、来源、字幕和发布绑定校验。

## 浏览器验收

Windows Chromium155、真实生产构建和回环HTTP服务，使用自有18.2秒双音轨MP4与合成发布回执，不调用真实提供商。

- 相同17秒摘要延迟下，工作台677毫秒连接，997毫秒已打开可编辑字幕，约18.36秒后显示已验证成片。期间状态轮询继续返回；15秒后的局部说明正常显示。输入备注未被晚到结果覆盖，未保存修改时下载仍禁用。这是单次受控验收数据，不是普遍响应保证。
- 检查期间保存字幕，点击到保存确认526毫秒；19秒后内容仍为新修订，旧下载入口没有恢复。
- 人为中断独立检查请求，只显示成片区域错误；字幕仍可编辑、服务仍连接，点击局部重试成功。
- 实际下载MP4为288519字节，SHA-256与已验证成片一致，页面MP4正文读取及对象URL计数均为0。
- 仅破坏自建输出文件一个字节，刷新后撤下成片入口，轻状态不复用旧路径，原下载地址返回410且无附件头。原素材保持不变，自建服务与浏览器已关闭。

失败日志保留：初次带网络事件采集的脚本发生会话超时，但浏览器记录响应48毫秒，具体原因未确认；清洁会话去除该采集后正常。另一遍脚本在输入后使用精确label定位失败，DOM及角色定位确认输入完整，最终清洁夹具采用角色定位全程通过。复用页面时仅跳到相同token片段不会重载预览，导致一次“未见检查提示”；最终使用新入口消除该歧义。清理时的额外恢复显示探针被提前关闭，不列为通过项目；自建输出字节已恢复。正常取消旧请求后服务端可能记录对已断开连接写错误响应的堆栈，不影响已验证的页面状态和请求释放，本轮未宣称消除这项日志现象。

## 回归与发布门禁

新增后端9项、前端21项回归，保留先失败再通过的证据。前端完整31文件541项、26次回环HTTP及生产构建通过。冻结223份源代码、测试与前端配置。定向阶段修复默认HTTP调用的兼容性回归，并更新受真实查询参数影响的前端传输模拟；没有修改普通15秒读取期限。

完整后端第一遍运行1554项，出现一项旧keepalive测试的WinError10053。原样单独20次通过不能解释历史失败；受控延迟第三次POST正文，直到服务器已经发503并关闭，三次均复现同样错误。关闭准入检查先于正文读取，迟到的正文可能使Windows连接重置，已发出的503因此无法被客户端读取；不是1秒测试期限耗尽。

该测试验证请求租约释放及关闭后的准入拒绝，第三次请求不需要正文。仅改为认证的无正文GET，保留前两次POST、租约、空闲关闭及503断言，原超时不变。相同“先关闭、后读取响应”探针由失败转为通过，相关33项通过。生产关闭流程未修改；底层退出阶段POST早回应/迟到正文的传输限制仍存在，不伪称本轮修复。

## 收益和边界

收益是成片校验时仍能进入工作台并核对字幕；完整摘要本身没有加速。代价是每次相关预览增加一个独立小JSON请求和相应请求生命周期状态。浏览器测试使用Windows Chromium、真实回环服务、生产构建和自有合成素材；发布回执不代表人工审核、云端识别、真实长片、其他浏览器或原生桌面壳验收。没有调用真实提供商或修改真实账户。
