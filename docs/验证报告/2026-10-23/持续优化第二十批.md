# 第36轮：直接下载 MP4

基线 `35cf6dce47916ab489fa719bf0891d3c5a4abf89`。用户要求补齐直接下载 MP4，避免大视频占用过多内存，浏览器验收通过后上传 GitHub。本轮只计一次产品改进；上次五轮反思35，下次40。

## 用户可见变化

原文草稿、双语草稿和审核版成片增加直接下载按钮。浏览器负责附件传输，MP4 下载不将整个视频读入 Blob 或创建视频对象 URL。字幕文件的既有下载方式保留。提示只说明“已交给浏览器下载”，实际进度和完成状态以浏览器下载列表为准。

未保存修改、保存等待、版本冲突、任务运行和过期预览不允许发起下载。预检期间防止重复点击和重新导出；切换项目、刷新预览或编辑字幕会取消过期预检，已交给浏览器的下载继续。

## 文件和会话绑定

下载身份绑定项目、成片类别、输出摘要和发布绑定，不依赖会跨修订复用的文件名。先建立 HttpOnly 会话，再对同一下载地址进行有期限的 HEAD 检查；GET 重新验证当前成片并从已校验的同一文件句柄发送。文件校验复用有代际检查的有限缓存，传输块不超过256 KiB。

浏览器请求的地址不包含会话凭据。失效项目/版本返回409，缺失或无效成片返回410；错误没有附件头。使用同源隐藏下载目标，避免弹窗阻止和替换主页面；仅下载错误文档允许同源框架读取。最多保留两个目标，不用固定超时中断长下载。

## 浏览器验收

Windows 上的 Chromium 155.0.8059.85，真实生产构建、回环 HTTP 服务和独立合成素材。原文路径重新运行本机 Whisper small，18.2秒双音轨素材生成4句，然后由浏览器发起 CPU MP4 导出和新增按钮下载。没有调用识别或翻译提供商，没有使用真实账户。

- 原文草稿、双语草稿、审核版下载，共5份保存文件，尺寸和 SHA-256 与对应成片一致。双语/审核版使用明确标注的合成发布记录，未声称本次进行了人工审核或真实云端生成。
- 256 MiB 合法 MP4 传输夹具采用 ISO BMFF `free` 填充块；FFprobe 确认可解析。连续启动两次同类下载均完整保存，替换下载目标没有中断已开始的传输。
- 两次下载期间采样114次：页面 JavaScript 已用堆由6,187,636字节至最高7,647,128字节；MP4 Blob/ArrayBuffer读取和对象 URL 次数均为0，前端仅发HEAD预检。该测量不包含浏览器下载管理器或整机内存，不是任意长片的内存上限。
- 另一次较大文件下载尚未完成时，实际进入账户设置页，随后下载完整完成。没有填写或保存账户信息。
- 在HEAD成功后移走自建成片，实际GET返回410，页面显示失效原因，没有下载错误文件。恢复原字节后保留成果；所有自建服务与浏览器已关闭。

保留验收中的失败证据：第一次按时间延迟移文件未赶上GET；改用服务端钩子，清除残留的延迟路由后得到确定的失败响应。初次页面切换探针使用了不存在的标题，纠正定位器后验证“切换发生在下载完成之前”。没有把这些失败记录改成成功。

## 回归与发布门禁

新增后端18项、前端40项回归。实现前先用最初的定向用例观察缺失功能的失败，随后补充边界覆盖。前端完整30文件、520项及生产构建通过。完整后端首轮发现新增HTTP测试不符合离线禁网约束，以及旧的直接处理器测试缺少请求类型；改为内存中的真实处理器测试，保留禁网规则，31项相关检查通过。第二轮完整检查的一项临时凭据并发失败另作定向诊断，原日志保留。

该凭据失败项独立重跑通过；增加仅记录阶段耗时和异常类型的临时探针后，三轮同场景、9个子进程全部通过，最长锁等待0.595秒。空锁初始化交错另测三轮，追加写入均避开已经锁定的首字节。历史失败的内部原因仍未确认，不认定为环境偶发，不修改生产凭据逻辑或放宽任何测试限制。

第三次完整检查中凭据项通过，另有项目切换和进程存活两项旧测试失败，原始记录继续保留。定向探针确认：ABA 竞争切换测试将两次切换的锁外持久化也纳入0.3秒判断，注入0.35秒锁外写入延迟即可被误报为持锁；进程夹具则会在观察者保留句柄之前自行到期。后一探针重现提前退出后的存活断言失败，没有精确重现历史 WinError 87。这些证据支持修正测试同步方式，不支持修改产品锁或进程管理逻辑，也不能倒推历史失败的确切阶段。

ABA 用例改为验证竞争选择完成时，旧读取仍被屏障阻挡，然后验证旧选择提交被拒绝；其余响应时限保留。锁外延迟正对照通过，故意持锁的两个分支都被拒绝，整个文件8项通过。进程夹具改为先确认观察者已保留句柄，再开始原有有限等待；预阶段受观察者真实进程句柄约束，观察者消失时退出。原2秒终止回收时限不变，整个文件4项通过。直接与嵌套进程的13秒观察延迟正对照均通过，禁用真实进程所有权的两个负对照均被拒绝，观察者在握手前退出也回收了全部自建进程。修正只涉及测试，不另计产品轮数。

最终完整后端、HTTP、独立审查、精确提交CI与主目录同步结果以本批发布回执为准；未通过这些门禁不发布main。冻结校验覆盖221份源代码、测试与前端配置。发布不包含媒体、账户数据或本地验证夹具。

## 收益和边界

本轮补齐从应用取得当前成片的实际操作，并避免将既有字幕下载的整文件缓存方式用于MP4。此前没有这一MP4下载按钮，因此不把新增路径宣传为已测量的旧功能内存降幅。代价是一次会话刷新和HEAD预检，以及少量成片身份与下载目标状态。未测真实长片、其他浏览器或原生桌面壳，不宣称编码提速、固定内存节省比例或费用下降；外部程序在传输中原地改写文件不在原子发布的保证范围内。
