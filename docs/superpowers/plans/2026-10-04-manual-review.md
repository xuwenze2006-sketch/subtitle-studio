# 字幕人工校对闭环

用户已同意补齐逐句编辑、疑点标记、检查进度和整片草稿直接验收。沿用现有 React 校对页、本机 HTTP 服务和已验证的生成/费用流程，在当前实际使用的工作目录内保留既有修改，不新建遗漏未提交功能的旧版本工作树。

## 设计与验收标准

- 人工修订单独保存在所选字幕目录的“人工校对”目录，原始机器字幕、片段证据和费用不变。原始字幕变化时保留人工记录并提示冲突，不静默套用旧修订。
- 每句可修改原文、译文和起止时间，并保存未检查、已检查或疑点与备注。修改原文会让原译文待确认；不自动调用翻译服务。暂不增加删除、拆分、合并句子的操作。
- 保存使用版本校验和项目锁，防止两个窗口互相覆盖。下载、保存版本和压制都使用同一份修订快照，三种字幕同步生成。
- 整片草稿可直接记录人工抽检：仍核验真实生成完整性和源文件；至少明确检查20句（不足20句则全部），没有未解决的人工疑点或待确认译文。只记录实际勾选，不声称逐句看完。已有样片验收流程保留。
- 验收绑定当前原始结果、修订版本及其文件哈希。之后修改任一相关内容，旧验收不能用于导出；不自动启动压制或任何收费任务。
