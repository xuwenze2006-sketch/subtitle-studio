# 免费翻译总截止与停止 Implementation Plan

**Goal:** 解决持续慢响应绕过 socket 超时、停止后仍占用翻译队列的问题。基线 `33a729d`，本问题计第 11 轮；下一次五轮反思仍在第 15 轮。

**Design:** 每次免费请求使用一个受控 Python 子进程执行 urllib I/O，复用 `local_process.capture_process` 的 50 ms 轮询和 Windows Job 退出屏障。15 秒覆盖请求进程启动及 DNS、连接、TLS、响应头、正文；系统创建进程与退出清理不承诺硬实时。字幕 URL 通过匿名临时文件 stdin 传入，不出现在命令行。响应经有界 ASCII/base64 信封返回，父进程保留原 JSON 解析、HTTP 重试、备用端点、节流和缓存语义。

**Constraints:** 不请求真实提供商、不修改用户素材或账本。复用现有隔离工作树。离线测试标志传入子进程；离线 worker 仅允许无用户信息的回环 IP，禁用代理，并逐跳检查重定向。错误不回传含字幕的原始 URL 或异常文本。取消与超时转换保留异常因果链。使用惰性导入避免 runner/translate/local_process 循环依赖。
