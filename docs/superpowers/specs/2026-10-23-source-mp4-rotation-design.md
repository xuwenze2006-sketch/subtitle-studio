# 原文 MP4 竖屏导出修复

基线 `1b9bded17f4e302e8ba9f2f06ee74fc304b82e62`。原文 MP4 主流程已经发布；本轮按用户要求优先补齐实际使用缺口。4 秒合成视频已复现：源存储尺寸 160×90、旋转 90°，FFmpeg 正常自动旋转为 90×160，程序却因存储宽度不同而拒绝发布。字幕 ASS 也错误地沿用旋转前画布。

## 决策与范围

沿用 FFmpeg 自动旋转，在共享渲染中按显示方向计算字幕画布和校验尺寸。禁用自动旋转会让烧录字幕随画面转向；只放宽宽高校验又不能修复排版，因此均不采用。此为代理在既有授权下的实现选择，不冒称用户单独批准了内部方案。

显示矩阵优先于旧 rotate 标签；有完整矩阵时从矩阵计算角度，按 FFmpeg 的半离零取整后再做小于 1°转置判断，90°/270°交换宽高，180°和其他角度保持滤镜的尺寸行为。ffprobe 的整数 rotation 会截断精度，不能替代完整矩阵；缺矩阵文本时兼容旧 rotation/rotate 字段。损坏矩阵明确报错。尺寸校验仍须严格相等，帧率、帧数、时长、音轨和来源校验保持。无旋转输入的 ASS、编码参数和绑定不变，不强迫历史成片重新编码。不新增依赖或请求提供商。

## 验收与边界

先以回归复现旋转后的成片被拒绝和错误字幕画布，再实现最小修复。覆盖正负/折返角度、矩阵优先、真正尺寸错误以及重复导出。真实 FFmpeg 验证 90°/180°/270°、音轨和画面；真实浏览器完成新的隔离原文项目的保存和导出。完整回归、构建、独立审查及同提交 GitHub CI 成功后公开发布、同步主目录。只使用合成素材，不将短视频 CPU 证据当作真实长片、QSV 或原生桌面验收。

免费翻译补译失败丢失有效缓存的独立发现保留审计，后续处理；本轮集中原文 MP4，不将其混入本次修复。累计产品轮次完成后为33，下次五轮反思35。
