# 分段字幕流水线

用户已确认保留 small、优先准确，并要求执行上一轮提出的分段方案。

目标：约 5 分钟一段，片段一完成即可查看原文、检查报告和中文草稿；支持中断续跑，不再等待整部识别结束。复用本机 FFmpeg 与 whisper.cpp，不安装新模型，不调用付费接口。

实现 Python 标准库工具及中文桌面入口。默认 1 路 ASR、1 路翻译；支持手动选择 2 路 ASR，但不宣称未经实测的加速倍数。按静音附近切段，保留前后 2 秒上下文，记录原视频绝对起点。每段独立缓存和落盘，合并后仍是原视频时间轴。生成原文 SRT、中文草稿 SRT、双语草稿 SRT、需复核列表和状态文件。

自动检查只修复空白和无效时间范围、去掉完全相同的重复记录，标记长句、异常速率、接缝及重复疑点；不声称完成听音语义校对。翻译文字发送至 Google 免费翻译服务，单一队列、缓存、超时、有限退避；翻译失败保留原文并可续跑，中文结果不得以原文占位假装完成。

新任务不能覆盖原视频/用户已有字幕。项目目录有输入身份、配置及独占锁；不同输入或不同关键配置不能混用。文件原子写入，未完成片段不得标记完成。取消只停止本工具创建的子进程。

对已有 Subtitle Edit 长任务，优先等待它输出后复用其完整 SRT；不能因提速丢弃已运行的进度。使用中性合成语音验证本地识别与真实翻译，独立测试接缝、时间轴、并发、失败续跑。
