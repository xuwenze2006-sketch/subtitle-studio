# 云端字幕配置与使用

先按 [README](../README.md) 启动字幕工坊，再打开“API 设置”。本页说明软件支持的配置，不提供实时模型报价、免费额度或账户开通承诺。

## 服务与 Key

| 用途 | 程序接口 | Key 环境变量（兼容旧配置） |
| --- | --- | --- |
| 完整字幕识别 | 千问 / 百炼 `qwen-audio-3.1-asr-flash` | `DASHSCOPE_API_KEY` |
| 翻译 | DeepSeek 官方接口 | `DEEPSEEK_API_KEY` |
| 独立识别试听 | 硅基流动 `Qwen/Qwen3-ASR-1.7B` | `SILICONFLOW_API_KEY` |

优先在界面保存 Key。输入框保存后清空，Key 使用当前 Windows 用户 DPAPI 加密，位于 `%LOCALAPPDATA%/SubtitlePipeline/credentials.json`。接口不回显原值；新保存值优先于旧环境变量，保存不发送云端请求。

不同平台、地域及模型的 Key 不能因模型名称相似而混用。程序默认千问地址为 `https://dashscope.aliyuncs.com/api/v1`，也支持已列入白名单的千问平台地址 `https://maas.qianwenaiapi.com/api/v1`。只接受受支持的 HTTPS 主机，不跟随携带 Key 的重定向。先按自己账户的官方控制台核对地址、模型权限和计费方式。

硅基流动入口只生成试听文字；未取得经过验证的字幕时间戳时，不输出虚假的同步 SRT，也不能据此批准完整字幕流程。

## 核价与预算

保存 Key 和确认价格是两个步骤。填写实际核实的单价、日期和来源，确认框默认关闭；核价记录有效期为 7 天，过期后需要重新核对。

- 千问与 DeepSeek 配置使用输入、输出“元 / 百万 token”。界面默认数字只是填写参考，不能视为账户当前报价。
- 硅基流动配置使用“元 / 秒”，以账户模型详情为准；不能沿用旧的免费确认。
- 非密钥设置保存在 Windows 当前用户环境中。API Key 不写入项目文件或子进程命令行。
- 程序在发送前预留费用，返回可靠用量后结算；无法确认用量时保留保守估算。费用账本不是服务商账单。
- 默认项目预算为 20 元、追加请求停止线 18 元。共享同一 `--budget-ledger` 的项目共享预算；其他工具产生的费用不在本程序统计范围内。
- 未知提交状态保留费用预留并停止自动重发。先检查已保存的响应及账本，不要为了“重试”删除记录或新建另一份预算。

报价应从服务商官方页面和账户控制台核实：[百炼模型文档](https://help.aliyun.com/zh/model-studio/qwen-audio-3-1-asr-flash)、[千问模型页](https://www.qianwenai.com/models/qwen-audio-3.1-asr-flash)、[DeepSeek 价格说明](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)。充值、付款和账户开通在服务商官方页面操作。

## 制作、验收和恢复

1. 选择素材、字幕语言和项目目录，点击“准备样片”。此阶段仅在本机处理媒体。
2. Key、核价和样片条件满足后，明确点击开始识别或翻译才会发送相应请求。
3. 样片听看核对后再验收并处理整片；也可明确选择先生成未审核草稿。软件完成不等于人工验收完成。
4. 校对台保存人工修改、已核对状态和疑点；下载及 MP4 导出使用当前保存的修订版。
5. 继续任务时选择原项目目录，保留原始响应、账本和请求锁。取消不能撤回远端已经接受的请求。

详见[使用指南](使用指南.md)。不要把 Key、账户截图或带 token 的启动链接附在公开问题报告中。

## 配置看起来丢失时

先检查是否打开了不同服务实例、不同 Windows 用户或不同的数据目录。某些打包环境可能重定向 `%LOCALAPPDATA%`。加密凭据不能跨用户直接复制使用；保留原文件，不用一份配置覆盖另一份来碰运气。

更新源码后需重新启动后端；仅刷新网页不会更新后端校验。读取超时后可重新连接，但不要把业务写入回执丢失当作操作一定失败；先确认项目实际状态。
